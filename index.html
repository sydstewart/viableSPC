📊 StepChange Analyzer — Help

Preparing your CSV file

Your CSV must have at least two columns: a date column and a numeric value column. The analyser runs an automatic data quality check when you upload — if it detects blanks, zeros, or missing date periods it will show a yellow warning banner. A few common issues to avoid:

  • Numeric values with comma separators (e.g. 1,234,567) — these can break the CSV structure if not properly quoted. Before saving as CSV from Excel, format your value column as a plain number with no thousands separator, or ensure values are wrapped in quotes. Run the Data Validator to check for this.
  • Merged cells in Excel — merged date cells leave blank rows in the CSV. Unmerge all cells and fill each row with its own date before saving.
  • Mixed date formats — ensure all dates in the date column use the same format throughout. The Data Validator will flag inconsistencies.
  • Unsupported date formats — financial year formats like "2004-05" are not supported. Convert to a proper date (e.g. 01/04/2004) before uploading.

⚠️ Missing data: zeros and blanks

Missing values in your data can significantly affect stage means and confidence levels. There are two distinct cases to be aware of:

  • Case 1 — The row is omitted entirely from the CSV. The tool treats each row as the next observation in sequence. A large number of omitted rows compresses the time axis and may cause change points to be dated incorrectly.
  • Case 2 — A blank cell is present in the value column. A blank cell may be read by the tool as zero, which will severely depress the stage mean and may create false change points. Before uploading, filter your data in Excel and delete any rows where the value column is blank or zero when zero is not a valid measurement.

Getting Started

Prepare your data as a CSV file with at least two columns: a date column and a numeric value column. Then drag and drop the file onto the upload area, or click to browse.

Settings

  • Turn Length: Minimum number of points required in a segment before a change point can be detected. Default 5.
  • Loops: Number of bootstrap resamples. 1,000 is fast; use 5,000–10,000 for governance reports.
  • Conf %: Minimum confidence level required to declare a change point. 90% = sensitive; 95% = standard; 99.7% = conservative.
  • Show 3SD Limits: Adds ±3 standard deviation bands to the Step Change chart.

Privacy

Your CSV file never leaves your computer. All analysis runs entirely in your browser. No data is uploaded to any server. No login required.

About the method

Bootstrap CUSUM step-change analysis is a distribution-free method for detecting structural changes in time series data. It does not assume normality, making it particularly suited to healthcare safety data, incident counts, and other right-skewed metrics.

Based on Taylor (2000), building on Page (1954), Hinkley (1971), and Efron & Tibshirani (1993). Implemented at StepChangeAnalysis.com.
