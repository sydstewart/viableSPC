Release notes

What has changed in the StepChange Analyzer, newest first. Every release is tested before it goes live; how the analyser is tested explains how.

How the analyser is tested, and these release notes

Release 5.4 · 13 November 2026

  • New page, How the StepChange Analyzer is tested: the published method, an independent cross-check, automated checks before every release, and what testing cannot do.
  • This page of release notes.
  • Links to both, and to the guide and intended use, from the analyser page, the site footer and the Use the Analyzer menu.

A guide to using the analyser

Release 5.3 · 13 November 2026

  • New page, How to use the StepChange Analyzer, in six steps from preparing a file to using the result with care. The button on the analyser page now opens it.

Your file is checked as soon as you load it

Release 5.2 · 13 November 2026

  • A data check runs automatically when you load a file, and again when you change a column or a setting. Before anything is analysed, it shows how your numbers and dates will be read, rows that will be left out and why, missing periods and where they are, and anything that needs a decision.
  • A preview of the chosen columns makes a wrong choice easy to spot.
  • Series too short to give strong evidence are flagged.
  • Saved settings are reused only for a file with the same columns.
  • The separate Data Validator is no longer needed; Checking your data explains the built-in check.

You decide how special cases are treated

Release 5.1 · 12 November 2026

  • When periods are missing, you are asked whether they mean no activity (entered as 0) or no data (left out).
  • When several rows share a date, for example one row per sale, you can total or average them by date, week or month.
  • Values recorded as below or above a limit (such as <5) can be left out, set to the limit or set to half the limit; they are marked on the chart, and a change of limit is pointed out.
  • Daily working-day data is recognised, so weekends are not treated as missing.

Numbers and dates read more reliably

Release 5 · 12 November 2026

  • UK (1,234.5) and European (1.234,5) number styles are detected; when a file could be read either way, the analyser asks. A new Number Style setting lets you choose.
  • Currency symbols, percent signs and negatives in brackets are read correctly.
  • Each file is read under one date convention; a file that mixes day-first and month-first dates stops with examples instead of being misread. Impossible dates are rejected.
  • Dates are no longer shifted by time zones, and the date range no longer loses its first or last day.
  • Every result says how the data was read and lists any rows left out.

Clearer advice with every result

Release 4.2 · 12 November 2026

  • The note above the chart now explains that a detected change shows that the data shifted, not why, and that “no change found” does not prove nothing changed.

The seed explained

Release 4.1 · 12 November 2026

  • Help and Checking your StepChange results explain what the seed is and how to use it.

Results you can reproduce exactly

Release 4 · 11 November 2026

  • Every result records a seed; entering it with the same file and settings reproduces the result exactly. Exports also record the settings, a fingerprint of the data and the analyser version.
  • Results are always labelled with the settings actually used.

Clearer charts

Release 3.1 · 11 November 2026

  • Hover labels show full values instead of abbreviations such as 106.6k.
  • For data that cannot be negative, a lower limit below zero is no longer shown.

Numbers shown to the precision of your data

Release 3 · 10 November 2026

  • Results are never shown with fewer decimal places than your data, so small values (such as 0.0803) keep their meaning.

More accurate data warnings

Release 2 · 10 November 2026

  • False warnings about missing periods for UK dates have been corrected, and warnings now say where any gaps are.
  • Data warnings stay visible after recalculating and are included in PDF exports.

Reliability and guidance

Release 1 · 9 November 2026

  • Very long files no longer cause an error.
  • File contents are always displayed safely.
  • Advice on blanks and zeros corrected: blank values are left out, not treated as zero, and genuine zeros should be kept.
  • Intended use statement added, and a section on telling one gradual change from several steps.
